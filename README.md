# 🐍 Snake Game

Um jogo clássico da **Cobrinha (Snake)** desenvolvido para navegador, onde o jogador deve controlar a cobra, coletar alimentos e aumentar sua pontuação sem colidir com as paredes ou com o próprio corpo.

## 🎮 Funcionalidades

* 🐍 Controle da cobra pelo teclado
* 🍎 Sistema de comida
* 📈 Sistema de pontuação
* 📏 Crescimento da cobra ao coletar comida
* 💥 Detecção de colisões
* 🔄 Reinício da partida
* 🏆 Contador de pontuação

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura do jogo
* **CSS3** — Estilização da interface
* **JavaScript** — Lógica, movimentação e mecânicas do jogo

Este projeto foi desenvolvido para praticar conceitos de **JavaScript**, como:

* Loops
